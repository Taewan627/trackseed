# E9: candidate sources of tracks not created by the authors

Search date: 2026-11-12/13 (sandbox clock). Phase 1 only: nothing in this file is a validation or metric result.

## How the search was done (and what did not work)
- Web search (8 queries this phase: real-circuit centre-line datasets, F1 circuit GeoJSON, F1TENTH racetracks, PCG Benchmark, random closed racetrack generators in Python,
  convex-hull/Voronoi/Perlin generators, CarRacing track generation) plus the 15-row JS/TS survey of `experiments/e5/CANDIDATES.md` (not repeated here).
- The GitHub REST API is not usable here (HTTP 403 for unauthenticated calls). Every repository was inspected by `git clone` over HTTPS (depth 1/50); a repository that
  could not be cloned is marked. "Licence" = the LICENSE file at the repository root as fetched (header and the standard MIT/LGPL marker phrases were checked; the full text
  was not diffed against the SPDX texts). "Last commit" = date of the cloned HEAD.
- OpenStreetMap through the Overpass API is unreachable from the sandbox (`overpass-api.de`: connection reset by the proxy; `overpass.kumi.systems`: timeout), so OSM-derived data
  could only be used through intermediate repositories.
- This is a keyword search, not a systematic survey; generators that are not described with these words, or live outside GitHub, were not found. Candidates were not
  all read exhaustively; the Reason column says how far each inspection went.

## Algorithm families and independence of the generators actually used
- B1 (convex hull + midpoint displacement + spline) and B4 (jittered hull + displacement + Catmull-Rom) implement the same published idea; no shared code was
  established (I did not diff them; B4 states no source), so they are different implementations of one family.
- B2: bounded Voronoi regions (its README credits an earlier Unity project as the idea source).
- B3: radial checkpoints followed by a steered point (OpenAI Gym CarRacing); B5 is an adaptation of B3.
- The E5 generator (YannThorimbert) is a random base polygon with hairpin/S/chicane sections.
=> 4 families, 5 permissively licensed implementations here (B1-B5), of which B5 is a descendant of B3 and B4 is the same family as B1; in addition E5's generator.
  Counting only unrelated implementations: B1, B2, B3, B4 (four), +E5.
