# 원본 분석 및 웹 포팅 결정

분석 기준은 `../vclass/sketch_260512c/sketch_260512_2_bg.pde`입니다. 같은 이름의 중첩 폴더 사본도 동일한 SHA-256입니다. `../vclass/code.txt`는 같은 배경 오브젝트 구현 계열이며, `sketch_260512c.pde`는 배경 생성 기능이 없는 초기 계열입니다. ZIP은 실행하거나 덮어 풀지 않았습니다.

## 참고 문서

- `../vclass/TrackGenerator_Proposal.pdf`: 18쪽. 파라미터, Waypoint/Catmull–Rom, 레일 주행, 미니맵, 환경 배치의 기획을 확인했습니다. 관련 8·9·15쪽도 렌더링해 시각 확인했습니다.
- `../vclass/Processing_RacingTrack_Final_Presentation.pdf`: 14쪽. 생성 파이프라인, 코드 예시, 최종 기능과 향후 개선 방향을 확인했습니다.
- 같은 이름의 PPTX 두 개는 위 PDF의 편집용 참고 자료로 두고 웹에 포함하지 않았습니다. Processing 충돌 로그는 실행 지시나 기준 코드로 사용하지 않았습니다.

## 확인한 경계조건

1. 원본 `sceneDensity = 0`에서 `n = 0`, 정수 `STEPS2 = totalPts / n`이 0으로 나누기를 일으킵니다. 웹은 수가 0이면 즉시 빈 배경 목록을 반환합니다.
2. 원본 높이 3.7주기는 경계가 불연속입니다. 첫 점을 복사하는 것뿐 아니라 높이 함수 자체를 정수 주기로 바꿨습니다.
3. 원본 직선 선택은 중복 추첨을 반복하는 while입니다. 웹은 셔플 후 필요한 수만 선택해 유한 시간에 끝납니다.
4. 원본 미니맵의 고정 좌표 범위와 고정 선 두께를 제거했습니다.
5. 원본 장애물은 carT만 비교해 옆으로 피해도 충돌할 수 있습니다. 웹은 실제 월드 X/Z와 높이를 검사합니다.
6. 원본은 그리기 명령을 매 프레임 반복합니다. 웹은 도로 메시를 유지하고 차량 변환·카메라·미니맵 마커만 갱신합니다.
7. 직선과 Catmull–Rom 구간의 접선까지 연결하는 알고리즘은 원본에 없습니다. 웹도 원본 평면 구조를 유지하며 이 특성은 알려진 한계로 기록했습니다.
8. `numCurves`는 실제 커브 개수와 달리 전체 Waypoint 구간 개수입니다. 웹 UI는 이를 '구간 수'로 명확히 표시합니다.
